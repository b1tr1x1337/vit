# Расписание ОГАПОУ «ВИТ»

Сайт с расписанием для всех групп. Работает на телефоне и компьютере. Запоминает группу студента, открывает сегодняшний день и подсвечивает текущую пару.

## Файлы

| Файл | Что это | Когда менять |
| --- | --- | --- |
| `index.html`, `style.css`, `app.js` | Сам сайт | Никогда |
| `groups.js` | Список групп | Только когда добавляется **новая группа** |
| `groups/12-e.js` и т.п. | Расписание одной группы | **Каждую неделю** — только у тех групп, что изменились |

Для каждой группы — свой файл. Обновляете только присланные мной файлы, остальные не трогаете.

---

## 1. Выложить сайт в интернет (один раз, ~5 минут, лучше с компьютера)

1. Зарегистрируйтесь на <https://github.com>.
2. Справа вверху **«+» → New repository**. Название, например `vit-schedule`, выберите **Public** → **Create repository**.
3. Нажмите ссылку **«uploading an existing file»**.
4. Распакуйте архив и перетащите в окно **всё содержимое папки**: файлы `index.html`, `style.css`, `app.js`, `groups.js`, `README.md` **и папку `groups`** целиком.
5. Нажмите **Commit changes**.
6. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, **/ (root)** → **Save**.
7. Через 1–2 минуты появится адрес: `https://ВАШ-ЛОГИН.github.io/vit-schedule/`.

### Ссылки на группу
Можно давать прямую ссылку на группу — добавьте `#` и id группы:
`https://ВАШ-ЛОГИН.github.io/vit-schedule/#12-e`

На телефоне: меню браузера → **«Добавить на главный экран»** — будет как приложение.

---

## 2. Еженедельное обновление (~1 минута)

1. Присылаете мне скриншоты расписаний (можно сразу несколько групп).
2. Я возвращаю файлы групп, например `12-e.js`, `11-e.js`.
3. На GitHub откройте папку **`groups`** → **Add file → Upload files** → перетащите файлы → **Commit changes**.
   Файлы с тем же именем заменятся автоматически.
4. Если я прислал и обновлённый `groups.js` (появилась новая группа) — загрузите его в **корень** репозитория (не в папку `groups`).
5. Через 1–2 минуты всё обновится.

**С телефона:** откройте нужный файл в папке `groups` → ✏️ **Edit** → выделите всё, вставьте мой текст → **Commit changes**.

## 3. Формат (если захотите поправить сами)

`groups.js`:
```js
const GROUPS = [
  { id: "12-e", name: "12 Э", course: 3 },
  { id: "11-e", name: "11 Э", course: 3 },
];
```
`id` должен совпадать с именем файла в папке `groups` (`12-e` → `groups/12-e.js`). Только латиница, цифры и дефис.

Файл группы:
```js
addSchedule("12-e", [
  { start: "2026-11-02", days: [ [/* Пн */], [/* Вт */], [], [], [], [] ] },
]);
```
Пара: `{ n: 1, time: ["8.30-9.15", "9.20-10.05"], subject: "МДК 01.01 Экзамен", room: "403", teacher: "Коваленко Е.А.", exam: true }`

- `start` — дата понедельника; несколько недель можно хранить подряд, стрелки ‹ › переключают их.
- `exam: true` — выделить красным.
- Не удаляйте кавычки, запятые и скобки. Если что-то сломалось — загрузите мой последний файл заново.
