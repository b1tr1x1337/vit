# Расписание ОГАПОУ «ВИТ»

Сайт с расписанием для всех групп в стиле «стекла». Сделан в первую очередь для телефонов, на ПК тоже удобен.

**Возможности**
- **Неделя / День** — сначала вся неделя; нажатие на день открывает его подробно (на телефоне дни листаются свайпом, на ПК — стрелками ← →).
- Карточка **«Сейчас / Далее»** — какая пара идёт и сколько осталось.
- **Часы** (московское время) в правом верхнем углу.
- **Тема** — кнопка ☀️/🌙 рядом с часами. По умолчанию тёмная, выбор запоминается.
- **ОГАПОУ «ВИТ»** (логотип) — всегда возвращает на неделю своей группы.
- **Группа** — выбор группы (сайт её запоминает).
- **Поиск** — по группам, преподавателям и кабинетам. На телефоне окно поиска всегда над клавиатурой.
- **Звонки** — расписание звонков, текущий урок, перемены, обед своего курса.

## Файлы

| Файл | Что это | Когда менять |
| --- | --- | --- |
| `index.html`, `style.css`, `app.js` | Сам сайт | Никогда |
| `groups.js` | Список групп + расписание звонков | Новая группа или новые звонки |
| `groups/12-e.js` и т.п. | Расписание одной группы | Каждую неделю (только изменившиеся) |

## 1. Выложить / обновить сайт (с компьютера)

1. Откройте репозиторий на GitHub.
2. **Важно при обновлении:** загрузите **все** файлы из архива заново — `index.html`, `style.css`, `app.js`, `groups.js`, `README.md` **и папку `groups`**. Если заменить только часть файлов, сайт может сломаться.
3. **Add file → Upload files** → перетащите всё содержимое распакованной папки (не саму папку) → **Commit changes**.
4. Проверьте, что в корне репозитория лежат `index.html`, `style.css`, `app.js`, `groups.js` и папка `groups`.
5. Первый раз: **Settings → Pages** → Branch: **main**, **/ (root)** → **Save**.
6. Подождите 1–2 минуты и откройте сайт. Если видите старую версию — обновите страницу (на ПК **Ctrl+F5**, на телефоне потяните вниз).

Если что-то не так, сайт сам покажет, какого файла не хватает.

## 2. Каждую неделю

1. Присылаете скриншоты расписаний — я возвращаю файлы групп (например `12-e.js`).
2. На GitHub откройте папку **`groups`** → **Add file → Upload files** → перетащите файлы → **Commit changes**.
3. Новый `groups.js` (если прислал) — в **корень** репозитория.

С телефона: откройте файл → ✏️ **Edit** → выделите всё, вставьте мой текст → **Commit changes**.

## 3. Формат пары

```js
{ n: 1, time: ["8.30-9.15", "9.20-10.05"], subject: "МДК 01.01 Экзамен", room: "403", teacher: "Коваленко Е.А.", exam: true },
```
- `start` — дата понедельника; `days` — Пн…Сб (нет пар — `[]`); `exam: true` — красным.
- Два преподавателя: `teacher: "Иванов А.А. / Петров Б.Б."`.
- ФИО и кабинеты пишите одинаково во всех группах — так их объединит поиск.
