# Расписание ОГАПОУ «ВИТ»

Сайт с расписанием для всех групп в стиле «стекла». Работает на телефоне и компьютере.

**Что умеет**
- **Неделя / День** — сначала вся неделя, нажатие на день открывает его подробно (или переключатель «День»).
- Карточка **«Сейчас / Далее»** — какая пара идёт и сколько до конца.
- 🔔 **Звонки** — расписание звонков, текущий урок, перемены и обед для своего курса.
- 🔍 **Поиск** — по группам, **преподавателям** и **кабинетам**: показывает их расписание на неделю.
- Запоминает выбранную группу, светлая/тёмная тема по настройкам телефона.

## Файлы

| Файл | Что это | Когда менять |
| --- | --- | --- |
| `index.html`, `style.css`, `app.js` | Сам сайт | Никогда |
| `groups.js` | Список групп + расписание звонков | Когда добавляется **новая группа** или меняются звонки |
| `groups/12-e.js` и т.п. | Расписание одной группы | **Каждую неделю** — только у изменившихся групп |

Преподаватели и кабинеты собираются **автоматически** из расписаний групп — отдельно их вводить не нужно.

## 1. Выложить сайт в интернет (один раз, ~5 минут, лучше с компьютера)

1. Зарегистрируйтесь на <https://github.com>.
2. Справа вверху **«+» → New repository**. Название, например `vit-schedule`, **Public** → **Create repository**.
3. Нажмите ссылку **«uploading an existing file»**.
4. Распакуйте архив и перетащите в окно **всё содержимое папки**: `index.html`, `style.css`, `app.js`, `groups.js`, `README.md` **и папку `groups`** целиком.
5. Нажмите **Commit changes**.
6. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, **/ (root)** → **Save**.
7. Через 1–2 минуты появится адрес: `https://ВАШ-ЛОГИН.github.io/vit-schedule/`.

Если вы уже загружали прошлую версию — просто загрузите все файлы заново поверх (Add file → Upload files), они заменятся.

### Прямые ссылки
- Группа: `…/vit-schedule/#12-e`
- Преподаватель или кабинет: откройте его через поиск и скопируйте адрес из браузера.

На телефоне: меню браузера → **«Добавить на главный экран»** — будет как приложение.

## 2. Еженедельное обновление (~1 минута)

1. Присылаете мне скриншоты расписаний (можно сразу несколько групп).
2. Я возвращаю файлы групп, например `12-e.js`, `11-e.js`.
3. На GitHub откройте папку **`groups`** → **Add file → Upload files** → перетащите файлы → **Commit changes**. Файлы с тем же именем заменятся.
4. Если я прислал и обновлённый `groups.js` (новая группа) — загрузите его в **корень** репозитория.
5. Через 1–2 минуты всё обновится (на телефоне потяните страницу вниз).

**С телефона:** откройте файл в папке `groups` → ✏️ **Edit** → выделите всё, вставьте мой текст → **Commit changes**.

## 3. Формат (если захотите поправить сами)

Пара в файле группы:
```js
{ n: 1, time: ["8.30-9.15", "9.20-10.05"], subject: "МДК 01.01 Экзамен", room: "403", teacher: "Коваленко Е.А.", exam: true },
```
- `start` — дата понедельника недели; `days` — Пн, Вт, Ср, Чт, Пт, Сб (нет пар — `[]`).
- `exam: true` — выделить красным.
- Два преподавателя (подгруппы): `teacher: "Иванов А.А. / Петров Б.Б."` — найдутся оба.
- Пишите ФИО преподавателя и номер кабинета **одинаково во всех группах** — так поиск их объединит.
- Не удаляйте кавычки, запятые и скобки. Если что-то сломалось — загрузите мой последний файл заново.
